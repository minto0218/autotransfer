# 卓上手動治具 B3：購入品と印刷

この一式はバイアルなしでヘッド1個を手で動かすものです。Pico、サーボ、サーボ電源、全体アーム、長い外部アウターは使いません。G/T/Pの主糸を上向きに引き、各ドラムを動かします。ねじ山はCADで省略しているので、ねじは購入品です。

ねじ合計25本、ナット合計5個。長さは首下長です。M1.4×8は小頭2本とばねフック用の大きめの頭3本を区別します。M1.4ナットは不要です。M2×8の4本のうち2本は印刷部品の下穴へ、2本は支持台のナットへ締結します。普通の大きな頭のM1.4を全箇所へ使うと隣の部品に当たります。

小頭寸法の参考：[日東精工 0番ねじ頭部寸法](https://www.nittoseiko.co.jp/nitto-blog/2017/08/25/6)。個別の商品や販売在庫までは指定していません。市販ねじの公差を含め、頭の実寸を確認してください。

必要工具：0番の精密ドライバー、小型ナット用工具、ピンセット、ノギス、細いドリル（Ø0.8、1.1、1.5、2.1〜2.2など）、M1.4/M2タップ、ヤスリ、少量の接着剤。小穴を手でさらい、摺動部を合わせる仕上げを含む試作です。ねじの通し穴と、ねじ込む下穴を区別します。

## 0.4mmノズルで厳しい箇所

別体ピニオンはm0.5／24歯で、CAD上の歯先幅は約0.282mmです。戻し溝には約0.25mmの半径方向の肉厚、ねじり戻しスポークには高さ0.55mm、固定／動作ピンにはØ0.7mmの部分があります。耐久性を無視しても、形状が潰れれば動作確認ができません。このため、歯車・ラック・ドラム・カム・右ケースの端止めには**0.2mmノズルを推奨**します。これは本モデルの形状からの判断で、印刷実測の合格判定ではありません。

0.4mmの最細積層はZ方向を細かくしますが、歯先などXY方向の細さをそのまま再現できる保証にはなりません。0.4で試す場合は、全てを先に印刷せず、ピニオンと爪ラック各1個だけを出し、歯が分離して滑らかに噛むことを確認してください。

- 0.2mmノズル：通常PLA、積層0.06〜0.08mmを出発点。ヘッド一式をこのノズルで統一してよい。
- 支持台：0.4mmノズル、積層0.12〜0.16mmでよい。外観の最細設定は不要。
- 嵌合確認片：ヘッドと同じノズル・材料・補正で先に印刷。隙間0.15／0.20／0.25／0.30mmを比較。
- ドラムは平面をベッドへ。半割ケース・カムは分割面をベッド側へ。ガイド籠や側板の張出しには必要な支持だけを付け、歯・糸溝・軸穴・カム溝へ支持を埋めない。
- 側板と曲線梁の外面は同じ位置に収まる。外面をベッド側にし、曲面と輪の隙間の層を確認。新しい右ケースの円弧ガイドの下も層プレビューで確認。
- Ø0.7のピンは立て印刷を想定。小さなブリムを使い、先端と穴を現物合わせ。ピンの差込みでドラムを無理に押さない。

3MFは造形方向と個数をまとめた標準モデル配置データです。Bambuのプリンター／ノズル／材料／支持設定を保存したプロジェクトやG-codeではありません。スライス、層プレビュー、実際の印刷品質は現物確認が必要です。
