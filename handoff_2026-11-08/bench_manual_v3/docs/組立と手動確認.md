# 卓上手動治具 B3：組立と手動確認

## 構成

台底面がZ0、ヘッド基準がZ42。爪はZ26〜31、押し足はZ34からZ14まで動きます。バイアルの位置や高さを再現する台ではありません。旧・新2ヘッド、抜栓アーム、上部サーボは含みません。

中空2ドラム、平行爪、短い押し棒と半割カム、横向きJB-14×3を継続。B3は0°を機械的な戻り端とし、＋30°方向だけへねじる。短い動作用ピンを付けたままばねで0°へ戻す。長い0°ピンは組立時の穴合わせと保管用で、運転のたびに差し替えて0°を作る必要はない。端止めは丸穴の遊び分で角度を決めず、ピンが当たる接線方向の平面で公称0°／＋30°を決める。印刷誤差・ピン穴の遊びは残るので初回に確認する。

外部の長いチューブを使わず、主糸3本をヘッド上のつまみへ直接結びます。そのため前版の外部チューブ固定クランプは外しました。短いPTFEライナー3本は曲がり案内の中に入れます。

## 組立順序

1. 嵌合片を印刷し、穴と軸の隙間を確認。全ての部品で糸溝、歯、案内面、カム溝のバリを取る。ねじ下穴をタップし、通し穴をさらう。Ø0.7固定ピンの穴は原寸を確認し、必要な分だけさらう。
2. 別体ピニオンを下把持ドラムの六角座へ入れ、S03（M1.4×6）2本を下から締める。主G糸と戻し糸を内部座へ先に通す。後からガイド籠の内側へドライバーを入れようとしない。
3. レール両端の着脱ストッパーはまだ付けない。左右の爪ラックをそれぞれの端から入れ、下ドラム＋ピニオンを上から入れて同じ位置で噛ませる。爪パッドはラックと一体。初期開口35mmに合わせてから、両端ストッパーを小頭M1.4×4各2本（計4本）で留める。片側だけから2本の爪を通そうとしない。中央の固定梁を横切れない。
4. T主糸を上ねじりドラムの内部座へ先に通し、上ドラムをガイド籠へS04（M1.4×8小頭）2本で留める。S05の大頭ねじと取り違えない。
5. 押し棒へØ1×5.8横ピンを入れ、棒との中央接触部だけに少量接着する。カム溝には接着しない。小さなカム合わせキー2個を片側の角穴へ入れ、半割カムを横ピンへ合わせて閉じる。キーは片側だけ仮固定してよいが、カム溝へ接着剤を入れない。別体の上押込みドラムを棒の上端から差す。P主糸と戻し糸も先に固定する。印刷ピンを試す場合も、変形やバリで動きを妨げていないか確認。
6. **ケースを閉じる前に**半割のねじり戻し輪を付ける。結び座の約0.1mm薄膜をØ1.6で深さ0.9mmさらい、T戻し糸を座内へ収める。半割輪を最終位置より1.7mm高くして左右から入れ、下げてS02（M1.4×5）各1本で上ドラムへ留める。
7. ケースの後ろの合わせキー2個を入れ、左右を開いてドラム・カム・棒・取付済みの戻し輪を挟み、カム後ろのキー溝をケースへ合わせる。S08（M2×16）2本とN02（M2）2個で後側を閉じる。右ケースの円弧ガイドは固定部で、上ドラムはその内側で動く。**ケースを閉じてから戻し輪を横へ通そうとすると、新しい円弧ガイドに当たるため順番を守る。** 下の押し足は一体でも、ケースとカムが開き、上のドラムが別体なので組める。
8. 主G/T/Pの糸を各ドラムの巻取り溝へ通す。初期姿勢を上から見た巻き方は、主G＝時計回り270°、主T＝反時計回り90°、主P＝反時計回り180°。戻し側はG＝反時計回り60°、T＝時計回り105°、P＝時計回り45°を目安に、HTMLの位置と合わせる。角度は初期姿勢の巻き残しで、動作中は増減する。印刷エンドビーズに糸を通し、抜けない結びにして内部座へ収める。糸の巻方向はHTMLの配線表示を参照。巻き重なりで溝から浮かないことを確認。
9. 主糸案内の蓋を外し、R8の90°曲線へ短いPTFEライナーを置く。中心線長約12.6mmで、端を現物合わせ。糸を通し、S01（M1.4×4）のうち3本で蓋を留める。残る4本は両端ストッパー用。ライナーを細い縦穴へ無理に押し込まない。
10. フェルール3個と後側コームを付け、残るS03（M1.4×6）2本で留める。今回は外部チューブを入れず、上へ出た裸線を手引きつまみへ通す。つまみの穴の上で抜けない結びにし、G/T/Pをペンで記入する。初期のつまみ下面はG＝Z112、T＝Z122、P＝Z102を目安。正確なこの高さにすること自体は機能要件ではないが、互いのつまみを同じ高さへ並べない。
11. ケースに付ける前に、側板の3段の棚へ案内輪を横から入れる。S06（M1.6×16）を**下から**通し、上にN01を付ける。輪の上下各0.2mmの隙間を保ち、ナットで輪を挟まない。上から軸を入れると後ろの梁に当たる。輪が3個とも独立して回るか確認。
12. G/T/P戻し糸を各戻し溝→R4自由案内輪→ばねの可動フックへ直接結ぶ。固定フックをS05の大きめの頭のねじへ掛ける。側板をS07（M2×8）2本でケースへ留める。戻し糸はヘッド内だけで、外部へ6本の糸を引き回す必要はない。
13. 爪の固定ピン2本と長い0°ねじり固定ピンを入れ、押し棒を上端へ。棒を上端に合わせ、横向きの上端固定ピンを差す。初期状態（開口35、ねじり0、押込み0）では、ばねの固定フックから可動フックまでの目安はG約18.09mm、T/P約16mm。糸長を結び直して合わせる。自然長14に対して初期の伸びはG約4.09、T/P約2mmであり、3本とも2mmではない。フック形状と初張力の個体差は実物で調整する。
14. 台の2穴に合わせ、残るS07（M2×8）2本を下から、残るN02（M2）2個をケースのナット座に入れて留める。5mmゲージは使わないとき台の手前に置く。

## 継続した保持・組立構造

- ドラム穴は真円ではなく二面幅。穴の平面は中心から±1.0mm、棒は±0.9mmで、片側公称0.1mmの摺動隙間がある。回転は平面の接触で伝達し、棒は上下に通り抜ける。穴と棒が離れて見えるのはこの隙間。ドラムを棒へ接着しない。
- ドラムは棒と一緒には下がらない。下はカム上端の受け肩、上はケースの固定ガイドで軸方向を捕捉。公称隙間は下0.1・上0.2mm。カム自体もケースのキーと2段の位置決め環で保持する。
- 二面幅の遊びは公称形状で片側約7°相当あり、実際の印刷で変わる。手引き量は理論値を目安とし、押し足が20mm動いたかを測る。回転の遊び・摩擦は実測対象で、駆動120°で常に正確に20mmを保証するものではない。
- 待機位置は新しい横向き上端固定ピンで棒を直接固定する。ばねを外したときの姿勢保持は、このピンを入れた状態で確認する。固定ピンを抜いた運転中は、ばね・主糸・カムで動かす。
- 下の爪キャリッジは上下のCレールで捕捉。上側の掛かりを片側0.1→0.5mmへ増やし、下側は0.8mm。ラック背面と上側にもガイドを追加。歯がピニオンに噛む面は開けてある。
- 爪を組むときだけ両端ストッパーを外し、各端から1本ずつ入れる。運転時はストッパーを4本のねじで留める。爪の固定ピンはこのねじの代わりではない。
- カムとケースのキーは別体。小さな部品を片側へ入れ、反対側を閉じてからねじで締める。キーは位置合わせ、ねじ／固定ケースは離れないための保持を担当する。
- 横フォロワピンはB1の6.3→5.8mmへ短縮。6.3mm品を使う場合は両端を約0.25mmずつ仕上げる。ピン端が外側の中空ハブへ擦れないか確認する。

## 手動で試す順番

最初は力をかけず、各部品が手で自由に動くことを確認します。つまみはばねの力で動くため、ゆっくり持って戻します。

1. **開閉**：短い動作用ピンを付け、ねじりを0°端へ戻した状態で爪の固定ピン2本を抜く。Gを引くと閉じる。35→5mmの理論引き量は約25.63mm。5mmゲージを爪の間へ入れて到達を確認し、それ以上強く挟まない。ゲージは保持力を測るものではない。
2. **運転準備**：長い0°ピンを短い四角頭の動作用ピンへ替える。T糸を余分に引かず、ばねでピンが0°の面へ着くことを確認。以後、ねじり往復中は短いピンを付けたまま。
3. **＋30°ねじり**：開口25mm程度にし、Tを約6.81mm引きながらGを約5.37mm戻す。開口を見て調整し、＋30°の面へ強く押し付けない。マイナス方向へ回さない。
4. **0°へ復帰**：Tを約6.81mm戻し、Gは約5.37mm引いて把持幅を保つ。Tを引き戻す力はばね、0°を決めるのは機械端。Tで途中角度を釣り合わせない。端へ着かないときは糸の擦れ・結び・案内輪の回転を先に確認する。
5. **押込み**：爪を開き、5mmゲージを外す。棒が上端にある状態で赤い上端固定ピンを左へ抜く。固定ピンを付けたままP糸を引かない。Pを約7.64mm引いて下降10mm、約15.29mm引いて下降20mm・棒120°回転。押し足はZ34→14。ゆっくり戻して、カムやケースが動かず棒だけ戻ることを確認。戻した後は棒とケースの横穴を手で合わせ、上端固定ピンを入れる。
6. 最後に開口35・ねじり0・棒上端へ戻し、爪のピン2本、ねじり0°ピン、棒の上端固定ピンの計4本を入れる。

手引き量は理想計算です。実物の引き量・戻り方・摩擦・結びの滑りはこの治具で測る対象です。バイアルやスポンジを使った押込み力、引き抜き、180°TF、駆動速度の検証はこの治具の対象外。ばね寿命の保証もしていません。

## 分解

主糸を保持しながら戻しばねを緩め、側板と案内蓋を外す。ケース横ボルトを外して半割を開いてから、戻し輪を外す。押し棒の足と上ドラムの間へ内部部品を永久に閉じ込める構造にはしていません。接着は横ピンと押し棒の中央だけに限定します。

## B3の0°合わせとTばねの設定

1. 短い動作用ピンを付け、ドラムを0°のストッパー面へそっと戻す。長い組立ピンの穴が合うかも確認。合わなければ印刷バリとピンの太さを確認し、無理に押し込まない。
2. T戻しばねのフック間を約16mm（自由長14＋予伸び2）にし、戻し糸を結ぶ。予張力ゼロにはしない。初張力は未公表なので実際の力は測定対象。
3. 主T糸は、0°端から引き離さずに大きなたるみだけを取ってつまみへ結ぶ。サーボを接続する場合も、この「0°端を引き離さない」巻取り位置をゼロとして設定する。
4. ＋30°へ引き、戻すと0°へ着くか確認。戻らない場合、最初から予張力を強くするのではなく、糸・案内輪・ドラムの摩擦を確認して調整する。

Tばね長は0°で16.00、＋15°で17.05、＋30°で18.09mm。最大伸びは約4.09mm。Gばねの参照角は従来の＋30°なので、初期のGだけは約18.09mmのまま。

Tのドラム内の糸固定座を継続するため、戻し側の参照角0°・巻き残し105°とした。初期の巻き方は従来と同じ105°で、T戻し糸の有効長を従来より約2.09mm長くする設定。寸法より、0°の端とばね16mmを現物で優先する。

## 曲線ブラケット

後側の取付部は丸い端部と曲線リブでつなぎ、一枚側板の肩と先端も丸くした。案内輪の上下の台は円形の外周と細くつながる輪郭。取付ねじ位置・案内輪軸・ばね固定点・部品数は継続。側板の外面に曲線リブも収まるので、以前の0.5mmの梁張出しはなくなった。外面をベッド側にして置き、輪の隙間や軸穴へ支持を入れない。

0°復帰の確認ではG糸も開口を維持するよう操作する。G/Tは連動するため、3本の糸を全て放しただけで全機構が初期位置へ揃うことを保証する構成ではない。保管・電源OFFの位置固定は従来どおり各固定ピンを使う。
